All three SVGs are project-owned, generated with Python's standard library, with
no external fonts/art, screenshots or illustrative benchmark numbers. Each has an
accessible title/description, fixed light background and explicit scope labels.

The [source manifest](sources.json) pins documentation base
`f97070dddc1cb1788d4b1fab85c58da650a9f552` and SHA-256 of every consumed original
Git blob. Actual tested experiment SHAs are separate, preserved in the generated
[measurement tables](../performance/measurements.md) and original manifests.

From the repository root, using an ordinary Python interpreter (no torch needed):

```sh
python docs/tools/build_figures.py
python docs/tools/build_figures.py --check
python docs/tools/verify_docs.py
```

The generator reads **committed original records at the pinned base** with
`git show`; it never executes benchmark or GPU drivers. It also writes the selected
measurement appendix and source manifest. `--check` compares exact generated bytes
without rewriting. The verifier independently parses SVG data attributes and source
rows, checks kernel counts and mathematical labels, XML and Markdown links, and
checks that source evidence still equals its pinned committed bytes.
