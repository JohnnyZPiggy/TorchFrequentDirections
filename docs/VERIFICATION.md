## Reproduce checks

```sh
python docs/tools/build_figures.py --check
python docs/tools/verify_docs.py
python docs/tools/verify_docs.py --run-example
python scripts/check_snapshot.py
```

The first two are stdlib-only, offline and allocate no accelerator. They compare
generated bytes, exact Git source SHA-256, SVG XML/title/description, numeric point
positions/intervals and kernel-bar lengths against original CSV/JSON; they also
resolve relative file and fragment links. The third requires an existing
CPU-only torch install: it executes the actual README Python block and independently
checks covariance/tail/right-projection bounds for its three outputs and all eight
eligible k. It is an example/math smoke check, not a benchmark or fresh full-suite run.
The last checks all 131 immutable SAE files and known template-link exceptions.

Machine results and local install/example observations are recorded in
[verification.json](verification.json). Generated figure provenance is in
[sources.json](assets/sources.json). The checked documentation SHA differs from
later evidence-only commits, which only add the verification record.

## Limits

External publication/PR URLs are linked rather than recursively downloaded by the
offline verifier; merged states were separately read through GitHub. Static badge
URLs assert only license/research-software status, not CI/release/coverage or speed.
Math review follows the accepted exact-arithmetic derivation; a finite numerical
smoke check is not a general proof. Historical timings are neither rerun nor pooled,
and no new GPU availability, architecture or torch-version support is claimed.
